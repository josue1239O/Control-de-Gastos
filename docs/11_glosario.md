# 11 — Glosario y Acrónimos

> **Norma de referencia:** ISO/IEC/IEEE 26514 — terminología para información de usuario.

---

## A

| Término | Definición |
|---|---|
| **Account (Cuenta)** | Fuente de dinero del usuario (efectivo, billetera QR o inversión). |
| **AES-256** | Algoritmo de cifrado simétrico de 256 bits usado para proteger la base de datos. |
| **Aporte (Goal Contribution)** | Cantidad de dinero que el usuario asigna a una meta de ahorro. |
| **APK** | Paquete de instalación de una aplicación Android. |
| **Android Keystore** | Almacén seguro del sistema donde se guardan claves criptográficas. |

## B

| Término | Definición |
|---|---|
| **Balance** | Diferencia entre ingresos y gastos de un período. |
| **BiometricPrompt** | API de Android para autenticación por huella/rostro. |
| **BOB / Bs.** | Boliviano, moneda oficial de Bolivia. |
| **Billetera QR** | Cuenta de pago digital (ej. pagos por QR), considerada "dinero rápido". |

## C

| Término | Definición |
|---|---|
| **Ciclo financiero** | Período contable configurable (por defecto el mes calendario). |
| **Categoría** | Clasificación de un ingreso o gasto (Alimentación, Transporte…). |
| **Contribución** | Ver "Aporte". |
| **CSV** | Formato de valores separados por comas, para exportación externa. |

## D

| Término | Definición |
|---|---|
| **DAO** | Data Access Object; interfaz de acceso a la base de datos en Room. |
| **DataStore** | Mecanismo de Android para guardar preferencias de forma segura. |

## F

| Término | Definición |
|---|---|
| **FK (Foreign Key)** | Clave foránea; enlaza una tabla con otra. |
| **Fijo/Común** | Gasto recurrente y previsible (alquiler, servicios). |
| **Flow** | Flujo de datos reactivo de Kotlin con emisiones asíncronas. |

## G

| Término | Definición |
|---|---|
| **Glance** | Biblioteca de Jetpack para widgets con Compose. |
| **Gasto Variable** | Gasto no recurrente o de monto cambiante. |

## H

| Término | Definición |
|---|---|
| **Hilt** | Biblioteca de inyección de dependencias para Android. |

## I

| Término | Definición |
|---|---|
| **IEEE 830 / 29148** | Normas de especificación de requisitos de software. |
| **Insight** | Mensaje automático que resume un patrón de comportamiento financiero. |
| **Inversión** | Cuenta de ahorro fijo o inversión; no es dinero de gasto diario (RN-02). |

## J

| Término | Definición |
|---|---|
| **JSON** | Formato de texto estructurado usado para respaldos. |

## K

| Término | Definición |
|---|---|
| **KMP** | Kotlin Multiplatform; permite compartir código con iOS. |
| **Kotlin** | Lenguaje de programación principal de la app. |

## L

| Término | Definición |
|---|---|
| **LockScreen** | Pantalla de bloqueo (PIN/biometría). |

## M

| Término | Definición |
|---|---|
| **Meta (Goal)** | Objetivo de ahorro con monto objetivo y progreso. |
| **MoSCoW** | Técnica de priorización: Must/Should/Could/Won't. |
| **MVP** | Producto Mínimo Viable. |

## O

| Término | Definición |
|---|---|
| **Offline-first** | Diseño que asume que no hay red; todo funciona localmente. |

## P

| Término | Definición |
|---|---|
| **Patrimonio** | Total de dinero del usuario (disponible + invertido). |
| **PIN** | Código numérico de acceso. |
| **Presupuesto** | Límite de gasto definido por categoría y período. |
| **Proyección** | Estimación de valor a fin de ciclo según el ritmo actual. |

## R

| Término | Definición |
|---|---|
| **Recurrente** | Transacción que se repite automáticamente (sueldo, suscripción). |
| **RF / RNF / RN** | Requisito Funcional / No Funcional / Regla de Negocio. |
| **Room** | Biblioteca de persistencia sobre SQLite. |

## S

| Término | Definición |
|---|---|
| **SAF** | Storage Access Framework; permite al usuario elegir dónde guardar/leer archivos. |
| **Saldo Disponible** | Dinero gastable = efectivo + billeteras QR. |
| **SQLCipher** | Extensión de SQLite que cifra la base de datos. |
| **SRS** | Software Requirements Specification. |

## T

| Término | Definición |
|---|---|
| **Tasa de ahorro** | Porcentaje de los ingresos que no se gastó. |
| **Transacción** | Registro de un ingreso, gasto o aporte a meta. |

## U

| Término | Definición |
|---|---|
| **UDF** | Unidirectional Data Flow; patrón de flujo de datos en una dirección. |
| **UI/UX** | Interfaz de usuario / experiencia de usuario. |

## W

| Término | Definición |
|---|---|
| **Widget** | Elemento interactivo en la pantalla de inicio del teléfono. |
| **WorkManager** | API de Android para tareas programadas en segundo plano. |
